Most git clients show a change as a list of files and lines. That tells you
what moved, but not what it means.

[Haunt](/projects/haunt) is a desktop git client for Windows, macOS and Linux.
It does the usual work: staging, committing, branches, merging, rebasing and
pull requests. It also reads the project by function.

## Changes by function

Open a commit, a range or your local changes, and Haunt lists the functions
that were added, changed, moved or removed. For each one it shows what calls
it and which tests reach it.

A risk line on top says where to look first. Reviewing a branch works the same
way, without switching to it.

## Maps of the code

Haunt draws the layers of a project and the imports between its parts. It
marks cycles and imports that break your own rules. It also finds unused code,
call paths from the entry points, and HTTP routes with their handlers.

## History that follows the code

A function keeps its history when it's renamed or moved to another file. Blame
can step back past a change, and Haunt shows who knows each part of the code.

## Languages

TypeScript and JavaScript are read with the TypeScript compiler, so their calls
are exact. That includes the script blocks of Vue, Svelte and Astro files.

PHP, Rust, Lua, Python, Go, Java, C#, Ruby, C and C++ are read with
tree-sitter. Their calls are matched by name.

No setup is needed. A `haunt.config.json` can add your own layers and import
rules.

## Local only

Haunt talks to no service on its own. It uses your own git, your credential
manager and your SSH agent.

It runs none of a project's code until you trust its folder. That means no
hooks, filters or scripts. Before you trust a folder, it shows what it would
run.

## Trying it

Haunt is built with Tauri, Rust and Nuxt. It's at version 0.3.7 and still a
pre-release. The installers aren't signed yet, so Windows and macOS warn the
first time you open it.

Installers are on the
[releases page](https://github.com/RazerGhost/haunt/releases), and the code is
at [RazerGhost/haunt](https://github.com/RazerGhost/haunt).
